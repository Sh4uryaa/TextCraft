# TextCraft — Java Text Editor

TextCraft is a desktop-based text editor developed using **Java Swing** as an Object-Oriented Programming (OOP) project. It aims to provide a simple, user-friendly interface for creating, editing, and managing text documents.

## Features

- **Text Editing:** Write and edit text in a dedicated editor area.
- **File Management:** Create, open, and save text files.
- **Find and Replace:** Search for text and replace matching content.
- **Undo and Redo:** Reverse or restore editing operations.
- **Keyboard Shortcuts:** Access common editor operations quickly.
- **Status Bar:** Display useful information about the editor.
- **Theme Support:** Switch between light and dark themes.


## Technologies Used

- **Language:** Java
- **GUI Framework:** Java Swing
- **Version Control:** Git and GitHub
